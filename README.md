**Предметная область:** «Учет участников спортивных мероприятий».

## Описание программы
Разработано консольное приложение на языке C++, которое позволяет вести учет спортивных соревнований, спортсменов и тренеров. 

## Обоснование использования контейнеров STL
В ходе выполнения работы были использованы все три типа последовательных контейнеров:
**`array` (Статический массив):** 
Используется в классе `SportsCommittee` для хранения списка соревнований. Количество турниров строго фиксировано (3 штуки), поэтому нет смысла использовать динамическую память.
**`vector` (Динамический массив):** 
Используется в классе `Event` для хранения спортсменов и тренеров. Размер соревнования заранее неизвестен. `vector` обеспечивает быстрый доступ по индексу (для удаления/редактирования) и эффективную сортировку алгоритмом `std::sort`.
**`list` (Двусвязный список):** 
Используется в классе `SportsCommittee` для хранения результатов фильтрации. В `list` операции добавления и удаления элементов из середины выполняются максимально быстро (без сдвига всех остальных элементов), что идеально подходит для временных списков фильтра. 

## Использованные алгоритмы и итераторы
**`std::sort`**: используется для сортировки участников по опыту.
**Итераторы**: активно применяются для обхода элементов (`begin()`, `end()`) и удаления конкретных строк из контейнера `list` с помощью `advance()`.
